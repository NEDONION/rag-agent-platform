# 文档配图

把截图放到这个目录，文件名与 `TROUBLESHOOTING_LOG.md` 里引用的一致即可自动显示：

| 文件名 | 内容 |
|---|---|
| `rag-stuck.png` | RAG 问答卡在「正在数据集中检索…」的界面截图 |
| `agent-delay.png` | Agent 对话 14:30 提问、14:40 才回复的截图 |
| `ci-nginx-fail.png` | CI 中 nginx 校验失败的 Actions 页面截图 |
| `runner-online.png` | GitHub Settings → Actions → Runners 中 runner 显示 Idle 的截图 |

建议宽度 1200px 以内，PNG 格式。
